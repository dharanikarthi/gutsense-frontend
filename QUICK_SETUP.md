# 🚀 Quick AI Model Setup (2 minutes)

## What You're Seeing
The app is working perfectly! It's just looking for your AI model files. This is a **one-time setup**.

## ✅ 3 Simple Steps:

### 1. Place Your Model File
- Find your `indian_food_classifier.h5` file
- Copy it to the **root directory** (same folder as `convert_model.py`)

### 2. Convert the Model
```bash
python convert_model.py
```

### 3. Refresh the Page
- The app will automatically detect your converted model
- Start analyzing food images with AI!

## 🔧 Troubleshooting

### Can't find convert_model.py?
It should be in the root directory. If not, create it with the conversion script.

### Python not installed?
Download from [python.org](https://python.org) or use your system's package manager.

### Still having issues?
Check the browser console (F12) for detailed error messages.
